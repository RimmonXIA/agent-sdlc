# Agent 与人类协作的 SDLC

探索在人类与 agent 共同承担软件开发工作时，信息、产出物与工具应如何组织，并用本项目自身的工作方式实践这些设计。

## 要解决的问题

让参与者能够理解当前目标与成果、辨认有效决定、接续工作，同时避免正式成果积累无关的过程信息。

## 按任务进入

- 处理明确任务：读相关成果和协作规则；不必通读信息模型与全部历史。
- 延续开放探索：从探索材料中的后续议题选取工作。
- 调整协作行为：读工作流程，明确需要改变的行为。
- 回答历史原因：先定位相关成果，再按需查询 Git。

## 工作方式

从实际工作中的信息需要出发，再选择文件、Git、任务系统或其他载体。探索可以使用现有工具的新用法，也可以提出新的组织方式。

使用本项目暴露问题、修改设计；不以记录数量或工具复杂度衡量进展。
